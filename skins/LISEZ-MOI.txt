SKINS - comment jouer avec ton skin Minecraft
=============================================

Deux facons :

1) Tu as un fichier .png (64x64, ou 64x32 converti automatiquement)
   -> SkinTool.bat  >  option 2  (importer un fichier .png)
   ou en ligne de commande :
      python _tools\skin.py import "C:\chemin\mon_skin.png" mon_skin
      python _tools\skin.py apply mon_skin

2) Tu veux le skin officiel de ton pseudo Java
   -> SkinTool.bat  >  option 3  (telecharger le skin d'un pseudo Java)
   ou :
      python _tools\skin.py fetch MonPseudo

Tu peux aussi simplement copier tes .png dans ce dossier,
puis SkinTool.bat > option 1 pour choisir celui a appliquer.

Pour revenir au skin vanilla : SkinTool.bat > option 5
