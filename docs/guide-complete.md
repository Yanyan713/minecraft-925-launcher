**925 official versions**: 103 releases, 761 snapshots, 61 alpha/beta. Downloaded from the
Mojang servers and verified by **SHA-1**.

| Content | Detail |
|---|---|

| 13346 asset objects | sounds, languages, fonts |
| 925 `start.bat` launchers | one per version |

**Total on disk: 54.25 GB**

## Play

```
D:\minecraft\launch_minecraft.bat        main menu (releases / snapshots / alpha-beta)
D:\minecraft\versions\1.21\start.bat     launch a version directly
```
Each `start.bat` starts the version with the right Java runtime, its own libraries,
its extracted natives and the shared assets.
Saves and options are per version (`instances\<version>\`).

Offline profile (`Player`): single player works; online multiplayer requires a real
Microsoft account.

## Skins

```
D:\minecraft\SkinTool.bat                 skin menu
skins\                                    drop your .png files here
```
Offline, the game shows the default skin stored in the jar. The tool
(`_tools\skin.py`) replaces that texture with yours inside the 925 jars, and backs up
the original textures in `_tools\skin_backup.json`: `SkinTool > 5` restores everything.

Two ways to add a skin: drop a `.png` (64×64, or 64×32 converted automatically), or
fetch the skin of a Java username from Mojang.

## Tree

```
D:\minecraft
├── launch_minecraft.bat        main menu
├── SkinTool.bat                skin menu
├── versions_index.csv          type, date, Java, size, SHA-1 per version
├── versions\<v>\               jar, json, natives\, start.bat
├── instances\<v>\              game directory (saves, options)
├── skins\                      your skins + ACTIVE.txt
├── libraries\                  shared dependencies
├── assets\                     sounds / languages (objects, indexes, virtual)
├── runtime\                    official Java runtimes from Mojang
├── server\                     official server jars (every version that has one)
├── _menus\                     per-category menus
└── _tools\                     skin tool + backup data
```

## Skins: useful commands

```
python D:\minecraft\_tools\skin.py status          active skin + state
python D:\minecraft\_tools\skin.py fetch <username> downloads and applies
python D:\minecraft\_tools\skin.py import <png>    imports a file
python D:\minecraft\_tools\skin.py apply <name>    applies an imported skin
python D:\minecraft\_tools\skin.py restore         back to the vanilla skin
```
